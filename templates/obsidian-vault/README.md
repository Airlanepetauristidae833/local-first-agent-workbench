# Knowledge Vault Starter

This is the starter Obsidian vault for Local-First Agent Workbench. Markdown is the
authoritative source for durable knowledge. Open WebUI Knowledge, vector indexes,
embeddings, and RAG stores are disposable derived layers that must remain rebuildable.

## Directory map

```text
00 Inbox       Temporary captures awaiting regular review
01 Projects    Work with a defined objective and completion criteria
02 Areas       Ongoing areas of responsibility
03 Knowledge   Reusable concepts, explanations, and methods
04 Papers      Literature notes, optionally linked to Zotero
05 Experiments Reproducible experiments and observations
06 Decisions   Architecture records and significant decisions
07 Meetings    Meeting notes and follow-up actions
08 Daily       Daily notes and work logs
09 Archive     Completed, superseded, or inactive material
90 Templates   Obsidian note templates
91 Attachments Images and other attachments
99 System      Vault governance and maintenance guidance
```

## First-time setup

1. Copy this directory to the final knowledge location on your computer.
2. In Obsidian, choose **Open folder as vault** and select the copied directory.
3. Under **Settings → Files and links**, set the attachment folder to `91 Attachments`.
4. Under **Settings → Templates**, set the template folder to `90 Templates`.
5. Begin with Obsidian's core features; add community plugins only when a concrete need arises.
6. Validate the structure and templates before initializing Git or another backup system.

Do not treat raw chat transcripts as durable knowledge. First extract verified conclusions,
supporting evidence, decision rationale, unresolved questions, and next actions.
